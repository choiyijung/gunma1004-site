최종 버튼/문구/URL 정리 확인
============================

적용 기준
1. 전화 상담하기 / 상담하기 / 상담 안내 문구 제거
2. 중간 빠른 확인·코스 카드의 상담하기 버튼 삭제, URL 없음
3. 상단 지역 버튼은 지역별 URL 연결
4. 하단 보라색 업체 박스는 "우리동네 인기업체를 한눈에 / 지역명 업체 / 바로가기"로 변경
5. 하단 보라색 업체 박스의 바로가기 URL은 지역별 URL 연결
6. 따라다니는 고정 배너는 "바로가기" 문구와 메인 URL https://www.gunmachonsa.shop/ 연결
7. tel: 전화 링크 제거

수정 HTML 파일 수: 1277
중간 카드 버튼 삭제 수: 3558
상단 지역 버튼 수정 수: 2370
하단 업체 박스 수정 수: 1186
따라다니는 배너 수정 수: 1186
tel: 잔여 파일 수: 0
금지 문구 잔여 파일 수: 0

예시
강남구 신사동 하단 업체 박스 바로가기 -> https://www.gunmachonsa.shop/Gangnamgu
수원시 장안구 연무동 하단 업체 박스 바로가기 -> https://www.gunmachonsa.shop/Suwon
따라다니는 고정 배너 바로가기 -> https://www.gunmachonsa.shop/
