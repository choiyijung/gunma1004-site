최종 버튼 수정 확인
====================
1. 상단 3번째 버튼: 인기업체 확인 → 예약 전 확인사항
2. 상단 3번째 버튼 URL: 지역 외부 URL → 같은 페이지 #check-point 이동
3. 예약 전 확인사항 섹션에 id="check-point" 추가
4. 상단 첫 번째 인기업체 바로가기 버튼은 지역별 URL 유지
5. 하단 보라색 업체 박스 바로가기 버튼은 지역별 URL 유지
6. 따라다니는 하단 고정 배너는 메인 URL 유지
7. 중간 빠른 확인/코스 카드 상담하기 버튼 삭제 유지
